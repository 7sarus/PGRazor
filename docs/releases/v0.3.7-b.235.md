# PGRazor v0.3.7-b.235

## New features

- **Joystick lock:** Hold the joystick outward to pop out a directional lock badge. Dragging onto the badge or tapping it locks steering in that direction. Tapping the joystick unlocks it.
- **Three-finger overlay toggle:** Tapping the screen with three fingers toggles on-screen buttons, menus, and IV overlays together. Includes an optional confirmation dialog with a "Don't show this again" checkbox.

## Improvements & fixes

- **Root-only packaging:** Switched release builds and workflows to root-only modules (`PGRazor-Root-module.zip`) and companion root APKs (`PGRazor-Root.apk`). Non-root builds are disabled.
- **Ubuntu CI runner:** Migrated GitHub Actions release and check runners to Ubuntu, making Android build-tool resolution OS-agnostic across Linux and Windows.
- **Branch version stamping:** Local builds and GitHub Actions workflows automatically stamp feature and PR branch names into module properties and companion APK version strings.
- **ARM64 ART hook stability:** Merged upstream fix preventing Vector hooks from overwriting ARM64 runtime hook backup buffers during startup.
- **Hundo feed tool:** Merged upstream standalone coordinate feed publisher.
