# PGRazor v0.1.0-alpha.4

Install **PGRazor.apk** below. It appears as **Pokémon GO** in the launcher and updates alpha.3 using the same signing key.

## Added

- **My Shinies** in Feed, using the friend code configured on the LivePokeMap website. Separate refresh interval and expiry handling; results are not restricted to Nearby's 1/3/5 km radius.
- **Display filters:** species list, minimum/maximum IV and level, XXS/XXL, always-show exceptions, Great/Ultra/Little League PvP ranks, shiny and background controls. My Shinies uses its supported filter subset.
- Local named filter presets, saved across restarts.
- **Export / import settings** in the main settings menu. Save a JSON backup through Android's file picker, then restore it after a reinstall or on another phone.

## Backup contents

Includes feature preferences, speed, favorites, map layers, Feed filters/presets and overlay positions. Excludes login tokens, current location, cooldown history and active routes. Import validates the file before writing; VGP remains off. Favorites contain coordinates, so keep your backup private.

## Validation

Automated parser, filter, backup-validation, compilation and packaging checks are run for this release. Live My Shinies authentication, provider filter behavior, and Android file-picker restore still need user validation on a phone. No new account-linking API or cloud preset mutation is used. LivePokeMap requires its own active subscription.
