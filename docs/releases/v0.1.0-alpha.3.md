# PGRazor v0.1.0-alpha.3

Download **PGRazor.apk** below and install it on an ARM64 Android phone. The launcher name is **Pokémon GO**; tap the **R** icon in-game for PGRazor controls.

## Added and improved

- Quick menu with Map, speed presets, Autowalk, Feeds, Favorites, Teleport, and Settings.
- Full-screen themed map and cooldown history, route looping, and Walk/Teleport actions for map pins.
- Nearby PokéStop, gym, and raid layers with game icons, team colors, defender counts, raid details, and boss names.
- LivePokeMap feeds for remote Pokémon, stops, gyms, raids, and stations. Requires a separate active LivePokeMap subscription.
- Feed icons now use bundled base-species sprites, gym team emblems, and raid boss/egg images instead of letter badges. Forms and shiny variants share the base-species image.
- Public GitHub Actions packaging with versioned release notes and downloadable APK/checksum/build information.
- Movable cooldown and VGP overlays with saved positions.
- Unlimited-incubator automation with shortest- or longest-distance priority; fixed egg ID conversion that caused an unavailable message.
- VGP stationary retry improvements, activity indicators, XXS/XXL transfer protection, and optional stop-on-cooldown. VGP stops when the app leaves the foreground.
- Discord link in the settings footer and refreshed feature documentation with a menu screenshot.
- Feed login layout and keyboard fixes, plus map loading improvements.

## Installation and validation

- Game baseline: Pokémon GO **0.433.1 / 2026101502**, ARM64.
- Updates from the renamed PGRazor alpha.2 builds use the same signing key and preserve app data. Official-store Pokémon GO and PGSharp use different signing keys and cannot be updated in place with this APK.
- Build and focused automated checks passed locally; this release is for user installation testing. End-to-end incubation and this exact release installation remain to be confirmed on a phone.
- `SHA256SUMS.txt` verifies the download; `build-info.json` records packaging details. This is an experimental pre-release.
