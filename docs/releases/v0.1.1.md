# PGRazor v0.1.1

## Changes

- **Smoother Quick Catch:** Return to the map without the brief Pokemon details screen or gray flash on supported manual catches. Includes faster completion from the first catch and preserves auto-transfer.
- **Optional IV and level displays:** Separate settings for the catch screen and caught Pokemon details. Inventory text has improved contrast against different backgrounds. Both settings are included in export/import.
- **Location spoofing toggle:** Turn spoofing off to use your phone's location. Disabling it stops simulated movement, and your choice persists across restarts. Fixed a crash when switching it off or reopening with it off.

## Installation

Download **PGRazor.apk** and install it over your existing PGRazor installation. Keep the existing app installed to preserve settings.

## Validation

Quick Catch transitions and inventory display readability were tested on the connected Pixel 11 Pro XL. The location fix successfully reopened to the map with spoofing saved as off. Build and device-free checks run in GitHub Actions.
