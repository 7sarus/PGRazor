# PGRazor v0.1.2

## Changes

- **Location privacy:** Use spoofing with the app's Android location permission denied while leaving system Location on for other apps. Spoofing also works with system Location off. Turning spoofing off restores normal device-location requirements.
- **Location reliability:** Fix startup hangs in the new location adapter and keep accuracy, timestamps, and provider status consistent when real GPS updates arrive.
- **Custom transfer keep list:** Search for species to protect from auto-transfer, regardless of other transfer rules. The list applies to manual and VGP catches and is included in settings backup.
- **Quick transfer control:** An optional Keep All overlay lets you pause transfers without reopening settings. Its choice persists between catches; the overlay appears only during encounters and requires Transfer on Catch to be enabled.
- **Compact berry picker:** Berry icons and inventory counts replace the longer labels. Select up to three berries in priority order; unavailable berries are skipped, and out-of-stock selections become usable when replenished. A fourth selection starts a new list, and Off clears it.
- **Overlay scaling:** Choose 100%, 75%, 50%, or 25% under Location & Overlays. Scaling includes the catch transfer overlay, berry overlay, and berry picker.
- **Joystick cleanup:** Remove the backing panel and make the joystick more transparent while retaining its drag handle.
- **Combined map taps:** Add a mode that walks on a single tap and teleports on a double tap on the in-game map.
- **VGP beyond the map:** Continue VGP while other in-game screens are open, excluding the Pokemon in your current manual encounter. Target markers remain map-only. Preserve IV display initialization alongside these changes.

## Installation

Download **PGRazor.apk** and install it over your existing PGRazor installation to preserve settings. You can also export a settings backup before updating.

For app-only location isolation, leave **Location Spoofing** enabled in PGRazor and set the app's Android location permission to **Don't allow**. System Location can remain enabled for other apps. Background location and unrelated permissions are unchanged.

## Validation

The recent features were tested during development on the connected Pixel 11 Pro XL. The location update reached a populated map with both precise and approximate app location permissions denied and system Location enabled, and was confirmed working by the user. GitHub Actions runs the maintained device-free checks and builds the release APK. Other devices and every feature combination have not been exhaustively tested.
