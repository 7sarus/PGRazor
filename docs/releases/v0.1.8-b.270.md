# PGRazor v0.1.8-b.270

## New features

- **Joystick lock:** Long-press the joystick center for 1.5s and drag in a direction to lock steering with haptic feedback. Long-press the padlock icon to unlock.
- **Joystick size:** Added a dp radius slider for the on-screen joystick.
- **Conceal username:** Added an Interface switch to replace your trainer name on game screens with `noneofyourbusiness` or a custom alphanumeric name.

## Improvements & fixes

- **Upstream v0.3.8:** Fixed Catch on map and Incense bird guard for game `0.439.0`, routed Auto throw catches through transfer rules, raised the incubator limit, and improved Auto Rocket VGP+ walking, leader prompts, and unspinnable stops.
- **Upstream v0.3.7:** Merged support for Pokémon GO `0.439.0`, Auto Rocket, Keep shadow/Dynamax/Gigantamax options, Global settings, Auto Lucky Egg and Auto Star Piece, Favorites actions, Skip teleport confirmation, and the standalone Catch preview switch.
- **Build & packaging:** Adopted `v0.1.8-b.<commits>` versioning with monotonic `versionCode` mapping, targeted `arm64-v8a` only, removed the in-app updater, and updated community links to Telegram.
