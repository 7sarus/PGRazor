# PGRazor v0.1.0

## Changes

- **Google sign-in fixed:** Sign in with Google opens your browser, lets you choose your account, and returns to Pokemon GO to finish signing in.
- Automated gym, raid, and Dynamax attacks and dodges pause while the Pokemon switch picker is open, so you can change Pokemon during battle.
- Discord release announcements support the Release Pings subscriber role.

## Installation

Download **PGRazor.apk** and install it over your existing PGRazor installation. Keep the existing app installed to preserve its settings.

## Validation

Google browser sign-in and an immediate app restart successfully loaded the authenticated map on a Pixel 11 Pro XL. Long-term session renewal has not yet been verified. Build checks run in GitHub Actions.
